# Video Assets

## Add Your Background Video Here

Place your video file in this folder:
- `cyber-bg.mp4` - Main background video for homepage

## Where to Get Videos

Free sources:
- **Pexels:** https://www.pexels.com/videos/ (Best option)
- **Pixabay:** https://pixabay.com/videos/
- **Coverr:** https://coverr.co/

## Recommended Search Terms

- "cyber security"
- "hacking code"
- "matrix"
- "data center"
- "programming"
- "cloud computing"
- "network"

## Video Specifications

Optimize your video before adding:
- **Resolution:** 1920x1080 or 1280x720
- **File Size:** Under 5MB (compress if needed)
- **Format:** MP4 (H.264 codec)
- **Length:** 10-30 seconds (will loop)

## Compression Tool

Use: https://www.freeconvert.com/video-compressor

Target settings:
- Quality: 70-80%
- Size: 3-5 MB

## Once Added

The VideoBackground component will automatically use `cyber-bg.mp4` from this folder.

If video is missing, the site will show gradient background instead (still looks good!).
